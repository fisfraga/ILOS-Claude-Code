# SPACE — Agent Instructions

## Purpose
The Structure dimension: holds your 12 Key Areas, active Projects, and Topics of interest -- what you are responsible for and building.

## When to Load
- User is doing project work or asking about projects
- User wants to review a specific life area
- User is mapping their life overview
- User asks about topics or interests

## Key Files (priority order)
1. `areas/README.md` — The 12 Key Areas guide with descriptions and templates
2. `projects/README.md` — Project management guide and active project tracking
3. `topics/README.md` — Topics as interest containers (Super Folders concept)

## Data Files (load only when needed)
- Individual area files (if created by user)
- Individual project files (if created by user)

## Rules
- SPACE lives partially in Tana (if configured). Local files are reference copies.
- Areas are ongoing and never truly complete -- they require continuous intentional design.
- Maintain **10-15 active projects** at any time. Fewer means stalling; more means scattered.
- Each area can have its own Vision, Purpose, and Strategy (VPS Framework).
- Areas, Projects, and Topics serve as **Super Folders** -- retrieval gateways that collect related items.
- The 12 Key Areas map to the 12 zodiac houses as archetypal energies (optional depth layer).
