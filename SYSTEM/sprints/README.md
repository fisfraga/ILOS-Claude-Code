## Architecture Principles

1. **Zero dependencies** — All HTML self-contained. No CDN, no npm, no server.
2. **Single SPA** — One HTML file with hash-based routing. New sprints ADD routes.
3. **Data-driven** — DAEDALUS reads real ILOS data at generation time. Never placeholders.
4. **Progressive enhancement** — Each sprint extends the DATA object and adds new renderers.
5. **Element-themed** — Fire (#ef6c00), Air (#0097a7), Earth (#2e7d32), Water (#1565c0), Ether (#9c27b0).
6. **Graceful degradation** — Features that need external data (transits, Tana) degrade to local-only mode.
