# ILOS-Template — Root Agent Instructions

## Purpose
Overview of the full Intentional Life OS workspace. This is the entry point if ROUTING.md was not loaded automatically.

## Dimensions

| Dimension | Directory | What It Holds |
|-----------|-----------|--------------|
| **QUANTUM** | `QUANTUM/` | Essence -- vision, personal context, self-knowledge |
| **SPACE** | `SPACE/` | Structure -- 12 Key Areas, projects, topics |
| **TIME** | `TIME/` | Flow -- goals, reviews, VPER cycle tracking |
| **MEMORY** | `MEMORY/` | Episodic memory -- wins, decisions, failures, experiences |
| **KNOWLEDGE** | `KNOWLEDGE/` | Methodology reference -- ILOS frameworks and principles |
| **IDENTITY** | `IDENTITY/` | Voice and writing style profile |
| **SYSTEM** | `SYSTEM/` | Configuration, setup, Tana MCP reference |

## How to Navigate

For task-specific module loading, see **ROUTING.md** in the workspace root. ROUTING.md maps user intents to the specific files that should be loaded.

Each dimension has its own `MODULE.md` with:
- Purpose and when to load
- Key files in priority order
- Module-specific rules

## Quick Start

1. Read `KNOWLEDGE/ilos-overview.md` to understand the system
2. Fill in `QUANTUM/personal-context/` files (start with `8-identity-values.md`)
3. Set goals in `TIME/active-goals.yaml`
4. Capture your first win in `MEMORY/wins.jsonl`
5. Run a weekly review using `TIME/templates/weekly-review.md`

## Core Principles (Always Active)

- **Gap to Gain** -- Always start with wins. Measure progress against your past, not an ideal.
- **Extreme Prioritization** -- Maximum 3 goals per time scale.
- **Review Before Plan** -- Complete the review before planning the next period.
- **VPER Cycle** -- Vision (Fire) > Plan (Air) > Execute (Earth) > Review (Water).
- **Intelligence Through Context** -- The more personal context you provide, the better the coaching.
