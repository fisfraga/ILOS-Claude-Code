# Security and contributions

This repository is a **read-only distribution** of the ILOS template. Only the maintainer pushes to it; pull requests are not accepted.

- **Your data stays on your computer.** ILOS has no server of its own; the dashboard binds to `127.0.0.1` only.
- **Found a security problem** (for example a skill that could leak data or run something unexpected)? Report it privately via GitHub's "Report a vulnerability" on this repository, or through https://fisfraga.com. Please do not open a public issue for it.
- **Never paste API keys, Tana tokens or workspace IDs** into an issue or discussion.
