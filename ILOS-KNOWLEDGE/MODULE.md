ILOS methodology reference: the universal frameworks, principles, and intellectual foundations that power the system.

- User asks about how the ILOS system works
- Agent needs framework context for coaching, planning, or reviews
- User wants to understand a specific concept (VPER, Gap to Gain, Elemental Wisdom, etc.)
- Onboarding a new user to the system

## Rules
- This is **universal methodology** -- the same for all users. Nothing here is personalized.
- Read `ilos-overview.md` first for orientation before diving into specific frameworks.
- These files inform how PARACELSUS coaches, plans, and reviews. They are not just documentation -- they define the system's behavior.
- When explaining concepts to users, use concrete examples and invitational language.
- Prefer concept files for quick questions; load lesson modules only when depth is needed.
