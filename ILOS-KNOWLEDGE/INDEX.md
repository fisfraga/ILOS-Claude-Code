# ILOS-KNOWLEDGE — Master Index

This folder contains all methodology knowledge for the Intentional Life OS (ILOS). Two types of content live here: **Concept Files** (concise agent-reference guides) and **Lesson Modules** (full teaching narratives). Use this index to find the right file for any user question.

---

## About This Folder

| Type | Where | Purpose | Token Size |
|------|-------|---------|-----------|
| **Concept Files** | Root (`*.md`) | Quick agent reference, definitions, framework summaries | Short (~1–5K each) |
| **Lesson Modules** | `lessons/` | Full teaching narrative: the "why," examples, philosophy | Long (~8–12K each) |

**How agents should use each type:**
- Load **concept files** for quick methodology questions, definitions, and framework reminders
- Load **lesson modules** when users ask "why does this work?", need onboarding, or want to deeply understand a topic
- Load concept files first; escalate to lessons only when depth is needed

## Concepts — 9 Reference Files

### `ilos-overview.md`
**One-line:** Complete system overview — the best starting point for any agent or user.
**Key concepts:** What ILOS is, local-first architecture, VPER cycle summary, three dimensions, elemental framework, purpose cascade, key components overview.
**When to load:** First orientation for any ILOS question. Start here before loading other files.

### `vper-cycle.md`
**One-line:** The core rhythm of ILOS — Vision, Plan, Execute, Review repeating at every time scale.
**Key concepts:** VPER phases and their elements (Fire/Air/Earth/Water), Review Before Plan principle, Gap to Gain in reviews, review sequence (Celebrate→Recognize→Redirect), cycle durations by time scale.
**When to load:** User asks about reviews, planning rhythm, weekly/monthly/quarterly cycles, or how the system flows.

### `quantum-space-time.md`
**One-line:** The three-dimensional framework organizing all life data (Essence / Structure / Flow).
**Key concepts:** QUANTUM dimension (vision + personal context), SPACE dimension (areas/projects/topics), TIME dimension (goals/wins/cycles), MEMORY layer (JSONL episodic logs), how everything connects.
**When to load:** User asks about life organization, data architecture, how the system is structured, or how to find things.

### `gap-to-gain.md`
**One-line:** The foundational mindset — measure progress against your past self, not against ideals.
**Key concepts:** Gap vs. Gain definitions, why comparison to ideals is exhausting, measuring backward for motivation, how to apply this in reviews, detachment from outcomes.
**When to load:** User is self-critical, feels stuck or insufficient, or asks about the review philosophy.

### `elemental-wisdom.md`
**One-line:** The five-element philosophy underlying ILOS (Fire/Air/Earth/Water/Ether).
**Key concepts:** Element-phase mapping, elemental balance in life, signs of over/under-expression per element, how to use elements for self-diagnosis and course correction.
**When to load:** User asks about elements, feels dominated by one mode (too much planning, not enough action, etc.), or needs elemental balance assessment.

### `aligned-goal-setting.md`
**One-line:** How goals connect upward to vision and downward to action — the alignment chain.
**Key concepts:** The goal cascade (FPs→MTP→HHGs→Annual→Quarterly→Monthly→Weekly), extreme prioritization (max 3), goal-setting philosophy (hold lightly, 10X thinking), alignment checks.
**When to load:** User is setting goals, wants to know how many goals to set, or needs to check if goals connect to vision.

### `intentional-planning-cycle.md`
**One-line:** Planning as an ongoing commitment across all time horizons, not a one-time event.
**Key concepts:** Year/Quarter/Month/Week planning structure, planning mindsets, the planning sequence (Expand→Prioritize→Define→Action), how cycles nest within each other.
**When to load:** User is starting a new planning cycle, wants to understand the planning process, or asks how often to plan.

### `intellectual-foundations.md`
**One-line:** The thinkers and frameworks whose ideas shaped ILOS.
**Key concepts:** Key authors (Tiago Forte, James Clear, Steven Kotler, Dan Sullivan, etc.), source frameworks (PARA, Atomic Habits, Flow research, Gap and Gain, Exponential Organizations), how each influenced ILOS design.
**When to load:** User asks about sources, intellectual lineage, or wants to go deeper into specific ideas in ILOS.

### `field-intelligence-layer.md`
**One-line:** The intelligence layer -- how AI reads, connects, and amplifies Quantum, Space, and Time.
**Key concepts:** FIELD as wrapping intelligence layer, 6 categories (context architecture, agents, skills, tools, HITL, AI principles), where FIELD is implemented (.claude/commands/, .claude/agents/, CLAUDE.md), compound intelligence.
**When to load:** User asks about AI architecture, what agents can see, how the system gets smarter, or the FIELD concept.

## Loading Strategy

### Load Concept Files When:
- User asks a specific methodology question ("what is Gap to Gain?")
- Agent needs a quick framework reminder before coaching
- Answering operational questions ("how many goals should I set?")
- Looking up data format specs (load `schemas.md`)

### Load Lesson Modules When:
- User asks "why" — why does this work, why do it this way
- Onboarding a new user to ILOS for the first time
- User wants to understand PARACELSUS or MCP in depth
- Explaining the full Purpose Cascade (FPs → MTP → HHGs → Goals)
- User questions the VPS Framework or the 12 Key Areas
- Deep coaching conversations where full context matters

### Token Budget Notes
- Concept files: ~1–5K tokens each — load freely
- Lesson modules: ~8–12K tokens each — load selectively based on topic
- `ilos-overview.md` is the single most important file — always load it first when the system is unfamiliar
- For most conversations, `ilos-overview.md` + one targeted concept file is sufficient
- Only load lesson modules when the concept file doesn't cover enough depth
