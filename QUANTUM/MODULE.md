# QUANTUM — Agent Instructions

## Purpose
The Essence dimension: holds your vision, personal context, and self-knowledge -- the atemporal truths about who you are.

## When to Load
- User is doing vision work (Favorite Problems, MTPs, HHGs, Life Manifesto)
- User asks about personal context or identity
- User references self-knowledge frameworks (astrology, Human Design, Gene Keys, etc.)
- Alignment checks that need to reference core identity

## Key Files (priority order)
1. `vision/favorite-problems.md` — The ~12 questions driving your curiosity and purpose
2. `personal-context/8-identity-values.md` — Core values and identity definition
3. `personal-context/0-life-vision-manifesto.md` — Deepest vision and beliefs
4. `vision/massively-transformative-purposes.md` — Guiding stars for decades
5. `vision/high-hard-goals.md` — Multi-year life-changing objectives

## Data Files (load only when needed)
- `personal-context/1-routines-and-habits.md` — Daily/weekly rhythm
- `personal-context/2-energy-patterns.md` — Optimal conditions and drains/sources
- `personal-context/3-relationships.md` — Key people and commitments
- `personal-context/4-non-negotiables.md` — Boundaries and constraints
- `personal-context/5-work-patterns.md` — Professional context
- `personal-context/6-geography-lifestyle.md` — Location and practical constraints
- `personal-context/7-life-stage.md` — Current season and bandwidth
- `personal-context/9-voice-profile.yaml` — Writing voice, tone, style dimensions (moved from the former IDENTITY module)
- `self-knowledge/` — Wisdom tradition profiles (optional deeper layer)
- `personal-context/archive/` — Quarterly snapshots of changed personal context files

## Rules
- This dimension is **atemporal** -- it does not change with weekly cycles. Update during quarterly or annual reviews.
- Use **invitational language** for self-knowledge content ("This energy invites..." not "You ARE...")
- Every placement in wisdom traditions has **gift AND shadow** expressions -- never frame challenges as purely negative.
- Personal context files are for the AI coach, not for publication. Encourage honesty over polish.
- Category 0 (Life Vision & Manifesto) is the foundation -- read it first when doing alignment work.
