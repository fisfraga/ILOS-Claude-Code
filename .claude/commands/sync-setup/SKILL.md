# Sync Setup → `/tana-setup`

`/sync-setup` is now part of `/tana-setup` (since ILOS 1.1; this pointer goes away in a later release).

Tell the user in one line: "`/sync-setup` is now part of `/tana-setup` — here is its sync-mode step." Then read `.claude/commands/tana-setup/SKILL.md` and run its **Step 5 (How much to sync)** and **Step 6 (First sync)**. If `SYSTEM/tana-ids.yaml` is still blank, run `/tana-setup` from Step 1 instead.
